# Thai medical-advertising flags (heuristic, not legal advice)

ใช้ใน Dimension D ของ `thrive-site-review` มีไว้ **flag** ถ้อยคำที่ควรให้ผู้รู้กฎหมาย/ฝ่ายขออนุมัติโฆษณาตรวจ ไม่ใช่คำตัดสินว่าผิดกฎหมาย
ทุก finding ในหมวดนี้ต้องติดป้าย `ต้องให้ผู้เชี่ยวชาญตรวจ` และห้าม optimize เองโดยไม่ได้รับอนุมัติ

## กรอบกฎหมายที่เกี่ยวข้อง (ตรวจฉบับล่าสุดทุกครั้งก่อนอ้าง)

- พ.ร.บ.สถานพยาบาล พ.ศ. 2541 (มาตรา 38: ห้ามโฆษณาสถานพยาบาลเท็จหรือโอ้อวดเกินจริง)
- ประกาศกรมสนับสนุนบริการสุขภาพ (สบส.) เรื่องหลักเกณฑ์ วิธีการ เงื่อนไขในการโฆษณาหรือประกาศเกี่ยวกับสถานพยาบาล: โฆษณาเชิงการค้าต้อง**ขออนุมัติก่อนเผยแพร่** (สบส. หรือ สสจ.) และ สบส. ปรับรายการคำต้องห้ามเป็นระยะ
- ผลิตภัณฑ์เสริมอาหาร/Nutraceuticals: กฎ อย. เรื่องการโฆษณาอาหาร (ห้ามอ้างรักษา บรรเทา ป้องกันโรค)
- เซลล์ต้นกำเนิด (Stem Cell) และ Exosome: ประกาศแพทยสภาจำกัดการใช้เฉพาะข้อบ่งชี้ที่รับรองแล้ว การโฆษณาเพื่อชะลอวัยหรือรักษาโรคทั่วไปเสี่ยงสูง

แหล่งอ้างอิงตั้งต้น: hss.moph.go.th (กองกฎหมาย สบส.) และ "คู่มือการจัดการโฆษณาสถานพยาบาล"

## Pattern ที่ต้อง flag

| ระดับ | กลุ่ม | ตัวอย่างคำ/รูปแบบ (regex แบบหลวม) |
|---|---|---|
| สูง | รับประกันผล / รักษาหายขาด | `หายขาด`, `รักษาให้หาย`, `การันตี`, `รับประกันผล`, `100 ?%` (เมื่อใช้กับผลลัพธ์), `เห็นผลทันที`, `ได้ผลแน่นอน` |
| สูง | ปลอดภัยเกินจริง | `ไม่มีผลข้างเคียง`, `ปลอดภัย 100`, `ไม่มีความเสี่ยง` |
| สูง | Superlative / เปรียบเทียบ | `ดีที่สุด`, `อันดับ ?1`, `ที่เดียวในไทย`, `แห่งแรก`, `เหนือกว่า`, `ล้ำสมัย`, `ทันสมัย`, `นวัตกรรมใหม่ล่าสุด`, `มหัศจรรย์`, `เป็นเลิศ` |
| สูง | Stem cell / Exosome / ฮอร์โมน | กล่าวถึงพร้อมคำอ้างผลลัพธ์ (`ชะลอวัย`, `ย้อนวัย`, `ฟื้นฟูเซลล์`, `รักษา`) |
| กลาง | ภาพ Before/After | รูปเปรียบเทียบก่อนหลังการรักษา |
| กลาง | รีวิว/คำบอกเล่าผลลัพธ์ | testimonial ที่บอกว่าหายหรือดีขึ้นจากบริการ |
| กลาง | โปรโมชันราคา | `ฟรี`, `ส่วนลด`, `ลด ?\d+ ?%`, `แถม`, `โปรโมชั่น` ที่ไม่มีเงื่อนไขชัดเจน |
| กลาง | ขู่ให้กลัว (ขัดแบรนด์ด้วย) | `อันตรายถึงชีวิต`, `อย่าปล่อยไว้`, `ก่อนสายเกินไป` |
| กลาง | อ้างรักษาโรคด้วย IV/วิตามิน/อาหารเสริม | `ล้างสารพิษ`, `ดีท็อกซ์`, `detox` + คำว่ารักษา/ป้องกันโรค |
| ต่ำ | ใช้ชื่อเสียงแพทย์ | `แพทย์ชื่อดัง`, `หมอดัง` |

## วิธีใช้

1. grep pattern ข้างบนใน `astro/src/content`, `astro/src/pages`, `astro/src/components`, `astro/src/data` และในเนื้อหา Sanity (ผ่าน crawl HTML ของ blog)
2. อ่านบริบทรอบคำทุกครั้ง: "ไม่หายขาดแม้ลองหลายวิธี" (บรรยายอาการ) ไม่ใช่การอ้างผล ไม่ต้อง flag
3. ข้อความใน FAQ และ JSON-LD (`acceptedAnswer`) นับเป็นโฆษณาด้วย
4. ไม่ต้องเสนอถ้อยคำแทนที่ "ผ่านกฎหมาย" ให้เสนอทางเลือกที่ลดความเสี่ยง และให้ผู้เชี่ยวชาญตัดสิน
