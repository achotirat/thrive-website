Vitamin D กับระบบภูมิคุ้มกัน
ทำไมคนไทยขาดมากกว่าที่คิด

Vitamin D ไม่ใช่แค่วิตามินกระดูก แต่เป็น Steroid Hormone ที่ควบคุมยีน 2,000+ ยีน รวมถึงการตอบสนองของระบบภูมิคุ้มกันทั้งหมด

📅 อัปเดต พฤษภาคม 2026 ✍️ พญ. ชนากานต์ ตระหง่านศรี ⏱ อ่าน 13 นาที

Vitamin D คืออะไร? ทำไมถึงเป็นมากกว่าวิตามิน

แม้จะมีชื่อว่า "Vitamin D" แต่ในทางวิทยาศาสตร์ Vitamin D ทำงานเป็น Steroid Hormone มากกว่าวิตามิน เนื่องจากมันไม่ได้ได้รับจากอาหารเพียงอย่างเดียว แต่ร่างกายสังเคราะห์ขึ้นเองเมื่อผิวหนังได้รับรังสี UVB จากแสงแดด และออกฤทธิ์ผ่านตัวรับ (Receptor) เหมือนฮอร์โมนทุกประการ

Vitamin D มีอยู่ 2 รูปแบบหลักที่สำคัญ ได้แก่ Vitamin D2 (Ergocalciferol) จากพืชและเชื้อรา และ Vitamin D3 (Cholecalciferol) จากแสงแดดและอาหารสัตว์ ทั้งสองรูปแบบต้องผ่านการแปลงที่ตับ (→25(OH)D) และไต (→1,25(OH)₂D หรือ Calcitriol) ก่อนจะออกฤทธิ์ได้

Vitamin D Receptor (VDR) พบอยู่ในเซลล์มากกว่า 30 ชนิดอวัยวะ รวมถึงเซลล์ภูมิคุ้มกันเกือบทุกชนิด ทำให้ Vitamin D มีบทบาทไกลกว่าแค่กระดูกและฟัน โดยควบคุมการแสดงออกของยีนที่เกี่ยวข้องกับภูมิคุ้มกัน การอักเสบ มะเร็ง และ Autoimmune diseases

Vitamin D กับระบบภูมิคุ้มกัน — กลไกโดยตรง

Vitamin D ส่งผลต่อระบบภูมิคุ้มกันทั้ง 2 ระดับ ได้แก่ Innate Immunity (ภูมิคุ้มกันโดยกำเนิด) และ Adaptive Immunity (ภูมิคุ้มกันปรับตัว):

🛡️
Macrophage Activation
กระตุ้น Macrophages ให้ผลิต Cathelicidin และ Defensin — Antimicrobial Peptides ที่ทำลายแบคทีเรียและไวรัสโดยตรง
🔬
Dendritic Cell Regulation
ปรับการทำงานของ Dendritic Cells ลดการอักเสบมากเกินไป และส่งเสริม Immune tolerance ป้องกัน Autoimmunity
⚖️
T Cell Balance
ปรับสมดุล Th1/Th2 และเพิ่ม Regulatory T cells (Tregs) ลดการอักเสบเรื้อรังและ Cytokine storm ที่อันตราย
💉
B Cell Antibody
ส่งผลต่อ B lymphocytes ควบคุมการผลิต Antibody ลด Autoantibodies และส่งเสริม Immune memory ที่ดีขึ้น
🔥
Anti-Inflammatory
ยับยั้ง NF-κB pathway ลดการผลิต Pro-inflammatory cytokines (IL-6, TNF-α, IL-17) ที่สูงเกินไปในโรคอักเสบเรื้อรัง
🧬
Antimicrobial Peptides
กระตุ้นยีน CAMP (Cathelicidin) โดยตรงผ่าน VDR ส่งผลให้เซลล์เยื่อบุทางเดินหายใจผลิตสารต้านเชื้อโรคได้เอง

ทำไมคนไทยถึงขาด Vitamin D ทั้งที่อยู่ในเขตร้อน?

หลายคนเชื่อว่าอาศัยอยู่ในประเทศที่มีแสงแดดตลอดปีอย่างไทยจะไม่ขาด Vitamin D แต่ความจริงคือ ผู้ใหญ่ไทยกว่า 50–70% มีระดับ 25(OH)D ต่ำกว่า 30 ng/mL ซึ่งถือว่าไม่เพียงพอ สาเหตุหลักมี 5 ประการ:

❌ ความเชื่อผิด: แค่อยู่ในที่มีแสงก็ได้ Vit D แล้ว

กระจกหน้าต่างกรองรังสี UVB ออกเกือบ 100% การนั่งทำงานใกล้หน้าต่างที่มีแสงเข้าไม่ช่วยให้สังเคราะห์ Vitamin D เลย

✅ ความจริง: ต้องให้ผิวถูกแสงแดดโดยตรง

รังสี UVB ต้องถูกผิวหนังโดยตรงเท่านั้น แนะนำ 15–30 นาทีต่อวัน เวลา 10.00–14.00 น. ให้แขนและขาถูกแสงโดยไม่ทาครีมกันแดด

❌ ความเชื่อผิด: ผิวคล้ำขาวสังเคราะห์ Vit D เท่ากัน

Melanin (เม็ดสีผิวคล้ำ) ดูดซับรังสี UVB ก่อนที่จะถึงเซลล์สังเคราะห์ Vitamin D ผิวคล้ำสุดขีดต้องการแสงแดดนานกว่าผิวขาว 6–10 เท่า

✅ ความจริง: คนไทยส่วนใหญ่ต้องเสริม Vitamin D

ผิวคล้ำ + ทำงานในอาคาร + ทาครีมกันแดด = ร่างกายสังเคราะห์ Vitamin D ได้น้อยมาก การเสริมซัพพลีเมนต์จึงจำเป็นสำหรับคนส่วนใหญ่

ปัจจัยลด Vitamin D ผลกระทบ หมายเหตุ
ผิวคล้ำ (Melanin สูง)ลด 90%+Melanin แข่งกัน absorb UVB
ครีมกันแดด SPF 30ลด 95–99%กรอง UVB ก่อนถึงผิว
ครีมกันแดด SPF 15ลด ~93%ยังกรอง UVB มากอยู่
กระจกหน้าต่างลด ~100%UVB ทะลุกระจกไม่ได้
ทำงานในอาคารตลอดวันขาดแสงแดดโดยสิ้นเชิงต้องได้รับจากอาหาร/ซัพพลีเมนต์เท่านั้น
อ้วน (BMI >30)ลดชีวภาพ 50%+Vit D เก็บในเนื้อเยื่อไขมัน ระดับเลือดต่ำกว่าจริง
อายุมาก (60+ ปี)ลดการสังเคราะห์ผิวหนัง 70%ผิวบางลง Precursor (7-DHC) ลดลง
Malabsorption (IBS, Celiac)ดูดซึมจากอาหารลดลงVit D ละลายในไขมัน ต้องการดูดซึมทางลำไส้ปกติ

อาการของการขาด Vitamin D

ภาวะขาด Vitamin D มักไม่มีอาการเฉพาะเจาะจง แต่อาการเหล่านี้พบบ่อยในผู้ที่มีระดับ 25(OH)D ต่ำกว่า 20 ng/mL:

😴
เหนื่อยล้าเรื้อรัง
เหนื่อยล้าผิดปกติแม้พักผ่อนเพียงพอ พลังงานต่ำตลอดวัน ไม่แจ่มใส งานวิจัยพบความสัมพันธ์ชัดเจนระหว่างระดับ Vit D ต่ำและ Fatigue
🦴
ปวดกระดูกและกล้ามเนื้อ
ปวดตามกระดูก โดยเฉพาะหลัง ขา ซี่โครง กล้ามเนื้ออ่อนแรง ในกรณีรุนแรงอาจเกิด Osteomalacia (กระดูกอ่อน) ในผู้ใหญ่
🤧
ป่วยบ่อย ภูมิคุ้มกันอ่อน
ติดเชื้อไวรัส แบคทีเรียบ่อยกว่าปกติ ไข้หวัดซ้ำ หลอดลมอักเสบ ปอดบวม เนื่องจาก Vitamin D ลดการผลิต Cathelicidin ต้านเชื้อโรค
😔
อารมณ์ซึมเศร้า
งานวิจัยพบความสัมพันธ์ระหว่างระดับ Vit D ต่ำและภาวะซึมเศร้า Vit D มีบทบาทในการผลิต Serotonin ในสมอง การเสริม Vit D ช่วยได้ในบางกลุ่ม
💇
ผมร่วงผิดปกติ
Vitamin D มีบทบาทในวงจร Hair follicle การขาด Vit D เชื่อมโยงกับ Alopecia areata และผมร่วงทั่วศีรษะ โดยเฉพาะในผู้หญิง
🩹
แผลหายช้า
Vitamin D กระตุ้น Growth Factors ที่จำเป็นในกระบวนการซ่อมแซมเนื้อเยื่อ การขาด Vit D ทำให้กระบวนการ Wound healing ช้าลงอย่างเห็นได้ชัด

ระดับ Vitamin D ที่เหมาะสม — ตรวจได้จากการเจาะเลือด

ระดับ 25(OH)D การแปลผล สถานะ
ต่ำกว่า 12 ng/mL ขาดขั้นรุนแรง (Severe Deficiency) รุนแรง
12–19 ng/mL ขาด (Deficiency) ขาด
20–29 ng/mL ไม่เพียงพอ (Insufficiency) ต่ำ

Vitamin D Toxicity (ระดับสูงเกินไป) เกิดได้ยากมากจากอาหารหรือแสงแดด แต่อาจเกิดได้จากการเสริมซัพพลีเมนต์ขนาดสูงมากต่อเนื่องนาน (มากกว่า 10,000 IU/วัน เป็นเดือน) อาการได้แก่ คลื่นไส้ อาเจียน กระหายน้ำมาก ปวดกระดูก ไตเสียหาย ควรตรวจ 25(OH)D ก่อนและระหว่างการเสริมปริมาณสูง

Vitamin D กับโรคที่ต้องระวัง

ระดับ Vitamin D ต่ำสัมพันธ์กับโรคหลายชนิด ซึ่งมีงานวิจัยสนับสนุน:

🦴
Osteoporosis
Vitamin D จำเป็นสำหรับการดูดซึม Calcium จากลำไส้ ขาด Vit D → ดูดซึม Ca ได้แค่ 10–15% แทนที่จะเป็น 30–40% → กระดูกบางลงเร็ว
🩺
Autoimmune Diseases
MS, Lupus, Rheumatoid Arthritis, Type 1 Diabetes พบบ่อยกว่าในภูมิอากาศหนาวที่มีแสงแดดน้อย Vitamin D ช่วยปรับ Tregs และลด Autoimmunity
💓
โรคหัวใจและหลอดเลือด
ระดับ Vit D ต่ำสัมพันธ์กับความดันสูง, ภาวะหัวใจโต, ความเสี่ยง Cardiovascular events เพิ่มขึ้น ผ่านกลไก Renin-Angiotensin modulation
🧠
ซึมเศร้า / อารมณ์
Vitamin D ส่งผลต่อ Serotonin และ Dopamine synthesis ในสมอง งาน Meta-analysis พบว่าการเสริม Vit D ช่วยลดอาการซึมเศร้าในผู้ที่ขาดอย่างมีนัยสำคัญ
🔬
เบาหวาน Type 2
Vitamin D มีบทบาทในการหลั่ง Insulin จาก Pancreatic beta cells และ Insulin sensitivity ระดับ Vit D ต่ำสัมพันธ์กับความเสี่ยง Type 2 DM สูงขึ้น
🌬️
ติดเชื้อทางเดินหายใจ
งาน Meta-analysis ใน BMJ (2017) จาก 25 RCTs พบว่า Vitamin D ลดความเสี่ยงติดเชื้อทางเดินหายใจเฉียบพลัน 12% โดยรวม และ 70% ในผู้ขาด Vit D อย่างรุนแรง

คำถามที่พบบ่อยเกี่ยวกับ Vitamin D

ระดับ Vitamin D เท่าไหร่ถึงถือว่าปกติ?
ระดับ 25(OH)D ในเลือด: ต่ำกว่า 20 ng/mL = ขาด (Deficiency), 20–29 ng/mL = ไม่เพียงพอ (Insufficiency), 30–100 ng/mL = เพียงพอ (Sufficiency) และนักวิจัยด้านภูมิคุ้มกันหลายท่านแนะนำระดับ Optimal ที่ 40–60 ng/mL สำหรับการทำงานของระบบภูมิคุ้มกันที่ดีที่สุด
ทำไมคนไทยขาด Vitamin D ทั้งที่อยู่ในเขตร้อน?
แม้ไทยจะมีแสงแดดมาก แต่หลายปัจจัยขัดขวางการสังเคราะห์ Vitamin D: ผิวคล้ำมี Melanin สูง ลดการสังเคราะห์ 90%+ ทำงานในอาคารตลอดวัน ไม่ถูกแสงแดดผ่านผิวหนัง ทาครีมกันแดด SPF 30 ลดการสังเคราะห์ 95–99% กระจกกรองรังสี UVB อย่างสมบูรณ์ และผู้ที่อ้วนมีไขมันเก็บ Vitamin D ไว้มาก ระดับในเลือดจึงต่ำ
Vitamin D2 กับ D3 ต่างกันอย่างไร?
Vitamin D3 (Cholecalciferol) จากแสงแดดและอาหารสัตว์ เพิ่มระดับ 25(OH)D ได้ 87% มีประสิทธิภาพสูงกว่า Vitamin D2 (Ergocalciferol) ซึ่งมาจากพืชและเชื้อรา งานวิจัยแสดงว่า D3 เพิ่มระดับในเลือดได้นานกว่าและมีประสิทธิภาพดีกว่าอย่างมีนัยสำคัญ แนะนำให้เลือก D3 เสมอเมื่อมีตัวเลือก
ควรทาน Vitamin D วันละเท่าไหร่?
ปริมาณขึ้นอยู่กับระดับเริ่มต้นและเป้าหมาย: บำรุงทั่วไป 1,000–2,000 IU/วัน แก้ไขภาวะขาด 2,000–4,000 IU/วัน ผู้ที่มีระดับต่ำมาก (<20 ng/mL) อาจต้องการ 5,000–10,000 IU/วัน ระยะสั้นภายใต้การดูแลแพทย์ ควรตรวจระดับ 25(OH)D ซ้ำหลังเสริม 3 เดือน เพื่อปรับขนาดให้เหมาะสม
Vitamin D กับภูมิคุ้มกันเกี่ยวข้องกันอย่างไร?
Vitamin D ทำงานเป็น Steroid hormone ผ่านตัวรับ VDR ที่อยู่บน Immune cells เกือบทุกชนิด ได้แก่ Macrophages, Dendritic cells, T lymphocytes และ B lymphocytes โดยกระตุ้นการผลิต Antimicrobial peptides (Cathelicidin, Defensin), ลดการอักเสบมากเกินไป (Anti-inflammatory), และปรับสมดุล T helper cells (Th1/Th2 balance) งาน Meta-analysis ใน BMJ (2017) พบว่า Vitamin D ลดความเสี่ยงติดเชื้อทางเดินหายใจได้อย่างมีนัยสำคัญ
จะรู้ได้อย่างไรว่าขาด Vitamin D?
อาการขาด Vitamin D ที่พบบ่อย ได้แก่ เหนื่อยล้าผิดปกติ ปวดกระดูกและกล้ามเนื้อ ภูมิคุ้มกันอ่อนแอ (ป่วยบ่อย) อารมณ์ซึมเศร้า ผมร่วงผิดปกติ และแผลหายช้า แต่อาการเหล่านี้ไม่เฉพาะเจาะจง วิธีที่แม่นยำที่สุดคือการตรวจเลือด 25(OH)D ซึ่งเป็นรูปแบบหลักที่หมุนเวียนในกระแสเลือด
