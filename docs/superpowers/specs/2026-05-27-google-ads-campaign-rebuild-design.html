1. High-level architecture

4 layers, separated by responsibility, so adding/editing a campaign means editing one row in a spreadsheet — not touching code or the Google Ads UI for each variant.

2.4 Tech implementation (Astro) — extend what already exists

Project already has the content-collection + per-service-page pattern in place. We extend the existing MDX schema with Traffic Secrets blocks rather than build from scratch.

# Existing today (do not refactor unnecessarily):
src/content/services/*.mdx      # 18 service entries with seo/hero/doctor/faqs
src/pages/<slug>.astro          # one Astro page per service, thin wrapper
src/components/                  # ServiceHero, FAQSection, DoctorAttribution,
                                 #   CTASection, LeadForm, ServiceCard

# New work for this spec — extend schema + add blocks:
src/content/config.ts            # define services collection schema (Zod) including
                                 #   optional symptomChecklist, epiphany, offerStack,
                                 #   riskReversal, socialProof blocks
src/components/lp/
  ├── SymptomChecklist.astro     # block 2 (NEW)
  ├── EpiphanyStory.astro        # block 3 — patient transformation (NEW)
  ├── OfferStack.astro           # block 4 — what's included (NEW)
  └── RiskReversal.astro         # block 6 (NEW)

# Existing components reused as Traffic Secrets blocks:
  - ServiceHero.astro    → block 1 HOOK
  - DoctorAttribution    → block 5 SOCIAL PROOF (author/credentials)
  - FAQSection           → block 7 FAQ
  - CTASection + LeadForm → block 8 CLOSE

Each priority page (food-intolerance, hormones-quiz, iv-drip) gets the 4 new blocks added to its MDX frontmatter + injected into its page wrapper. Pages without Traffic Secrets data render the existing layout unchanged (backwards-compatible — blocks are optional).

The bait/quiz CTA in this spec stays lightweight (embed Google Form / Typeform / link to legacy quiz). Full quiz engine is its own future spec — see Section 2.6.

2.6 Promoted to its own major feature (separate spec)

Quiz funnel — to be designed in a separate spec. Per the Traffic Secrets framework each LP is anchored by a bait/lead-magnet quiz; the Apr 2026 agency report shows the existing Food Intolerance quiz drives 92.66% of total conversions, so this is the largest single lever for ad performance. Treating it as a standalone feature so it can be designed properly rather than scoped in here.

For this spec: LPs ship with a lightweight bait — either embed an existing Google Form / Typeform, OR link to the existing /hormones-quiz / Food Intolerance quiz on the legacy site, OR fall back to the standard LeadForm. The full multi-question branching quiz engine is the quiz spec's job.

3. Copy A/B strategy + Google Sheet schema

3.1 Two layers of A/B testing

LayerMechanismWhen
A: Ad-level Responsive Search Ads — Google rotates 15 headlines × 4 descriptions automatically; reports per-asset performance + Ad Strength Day 1 — no setup overhead
B: Campaign-level Google Ads Experiments — 50/50 split, statistical significance computed for you After Layer A baseline exists (2026-06-11+)

3.2 Copy angle framework

Every headline maps to one of 5 angles so Google's learning data is labeled and we can see which angle wins per service.

AngleExample (Food Intolerance)
Painปวดท้องบ่อย หาสาเหตุไม่เจอ?

Authorityตรวจโดยแพทย์ ไม่ใช่เครื่อง
Specificityตรวจ 216 ชนิดอาหาร IgG

15 headlines = 3 per angle × 5 angles.

3.4 Workflow to add/edit a campaign (target: <30 min)

  1. Open Google Sheet → add row to campaigns tab
  2. vkasama (content writer) writes 15 headlines (3 per angle × 5 angles) + 4 descriptions in the ad_copy tab; can optionally use Claude as a brainstorming aid
  3. User / หมอนุ่น reviews the copy for medical-compliance accuracy
  4. List image filenames in assets tab (filenames must match the asset library)
  5. Export each tab as CSV
  6. Open Google Ads Editor → File → Import → CSV
  7. Review preview → Post changes to Google Ads
Collaborators on copy:
  • vkasama — content writer; owns headlines / descriptions / Thai tone; updates Sheet master directly.
  • หมอนุ่น / user — reviews for medical claims, compliance, voice.
  • Claude — on-demand brainstorming + scaffolding (for LP block content); not the owner of campaign copy.

4.3 Setup chain

GTM container → fires GA4 events → GA4 marks as "key event" → import to Google Ads as conversion → campaigns optimize toward it
  1. Paste GTM snippet → BaseLayout.astro
  2. GTM UI: configure 5 tags firing 5 events via CSS-selector triggers
  3. GA4 → Admin → Events → mark lead_submit, line_click, call_click as "Key event"
  4. Google Ads → Tools → Conversions → Import from GA4
  5. Wait 24-48h for data to flow → enable campaigns

4.4 UTM convention

utm_source   = google
utm_medium   = cpc | display | pmax | demandgen
utm_campaign = {service-slug}-{type}    e.g. food-intol-search
utm_content  = {ad-variant}             e.g. hookA-headlineA
utm_term     = {keyword}                (Search only)

Use Google Ads Final URL suffix template once, applies to all ads: utm_source=google&utm_medium={network}&utm_campaign={campaignid}&utm_content={creative}&utm_term={keyword}
