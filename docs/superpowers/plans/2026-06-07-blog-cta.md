# Blog CTA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add three inline soft-callout CTA blocks to every blog post — Top, Mid (JS-injected), Bottom — linking to the relevant Tier A service page with UTM tracking and GTM events.

**Architecture:** A new `BlogCTA.astro` component renders the card. It is placed at Top and Bottom as static Astro components. The Mid block is pre-rendered into a hidden `<div>` and moved after the 3rd H2 in the article body by a small vanilla JS snippet at runtime. Service data (`slug`, `title`, `shortDescription`) flows from Sanity via an expanded GROQ projection → Zod schema → page props.

**Tech Stack:** Astro 6, TypeScript, Sanity GROQ, vanilla JS (no framework for mid-inject), GTM data attributes, UTM query params.

## Task 3: Wire CTAs into `blog/[slug].astro`

**Files:**
- Modify: `astro/src/pages/blog/[slug].astro`

- [ ] **Step 1: Replace the full file contents**

Replace `astro/src/pages/blog/[slug].astro` with:

```astro
---
import { getCollection } from 'astro:content'
import BlogPostLayout from '../../layouts/BlogPostLayout.astro'
import BlogCTA from '../../components/BlogCTA.astro'

export async function getStaticPaths() {
  const posts = await getCollection('blogPosts')
  return posts.map((post) => ({
    params: { slug: post.data.slug.current },
    props: { post },
  }))
}

const { post } = Astro.props
const d = post.data

const faqItems = (d.faq ?? []).map((item) => ({
  question: item.question,
  answer: item.shortAnswer ?? '',
}))

const bodyHtml = (d.legacyHtml ?? '').replace(/<img(?![^>]*loading=)/g, '<img loading="lazy"')

const seoDescriptionFallback = (d.legacyHtml ?? '')
  .replace(/<[^>]+>/g, '')
  .replace(/\s+/g, ' ')
  .trim()
  .slice(0, 155)
  .trim()
const seoDescription = d.seo?.seoDescription?.trim() || seoDescriptionFallback

const ctaSvc = d.ctaService
const ctaProps = {
  serviceSlug: ctaSvc?.slug ?? 'contact',
  serviceTitle: ctaSvc?.title ?? 'Book your consultation at Thrive',
  serviceDescription: ctaSvc?.shortDescription,
  blogSlug: d.slug.current,
}
---

<BlogPostLayout
  title={d.title}
  publishedAt={d.publishedAt}
  updatedAt={d.updatedAt}
  authorName={d.authorName}
  authorTitle={d.authorTitle}
  category={d.category}
  mainImage={d.mainImage}
  seoTitle={d.seo?.seoTitle}
  seoDescription={seoDescription}
  noIndex={d.seo?.noIndex ?? false}
  canonicalUrl={d.seo?.canonicalUrl}
  slug={d.slug.current}
  faqItems={faqItems}
>
  {d.keyTakeaways && d.keyTakeaways.length > 0 && (
    <div class="blog-post__takeaways">
      <h2>สิ่งที่คุณจะได้เรียนรู้</h2>
      <ul>
        {d.keyTakeaways.map((point: string) => <li>{point}</li>)}
      </ul>
    </div>
  )}

  <BlogCTA {...ctaProps} position="top" />

  <div class="blog-post__body" set:html={bodyHtml} />

  <!-- Mid CTA: pre-rendered into a hidden wrapper, moved after 3rd H2 by JS -->
  <div id="blog-cta-mid-tpl" hidden aria-hidden="true">
    <BlogCTA {...ctaProps} position="mid" />
  </div>
  <script>
    const tpl = document.getElementById('blog-cta-mid-tpl')
    const bodyEl = document.querySelector('.blog-post__body')
    if (tpl && bodyEl) {
      const h2s = bodyEl.querySelectorAll('h2')
      if (h2s.length >= 3) {
        const cta = tpl.firstElementChild?.cloneNode(true) as Element
        if (cta) h2s[2].insertAdjacentElement('afterend', cta)
      }
      tpl.remove()
    }
  </script>

  {faqItems.length > 0 && (
    <section class="section faq-section">
      <div class="section-title-center">
        <span class="section-label">FAQ</span>
        <h2 class="section-title">คำถามที่พบบ่อย</h2>
      </div>
      <div class="faq-list">
        {faqItems.map((item) => (
          <details class="faq-item">
            <summary><h3>{item.question}</h3></summary>
            <p>{item.answer}</p>
          </details>
        ))}
      </div>
    </section>
  )}

  <BlogCTA {...ctaProps} position="bottom" />
</BlogPostLayout>
```
