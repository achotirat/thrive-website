# Blog HTML To Sanity Draft Importer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a local CLI importer that parses existing blog HTML files and creates Sanity `blogPost` draft documents for human review.

**Architecture:** A single Node ESM script under `tools/` handles discovery, parsing, Portable Text conversion, optional Sanity writes, asset upload, and report generation. The importer is conservative: unsupported HTML is flattened into readable Portable Text blocks and flagged in `docs/blog-import-report.md`.

**Tech Stack:** Node.js 22 ESM, `@sanity/client` from `astro/node_modules`, local `.env.local` loading, Sanity HTTP asset/document APIs through the client.

---

## File Structure

- Create `tools/import-blog-html-to-sanity.mjs`: CLI entrypoint, parser, Sanity writer, and report writer.
- Create `docs/blog-import-report.md`: generated by dry-run/import commands.
- No schema changes in this first implementation.
