# Thrive Website — Astro

New public marketing site for Thrive Wellness Center. Replaces Wix after cutover.

See `../CLAUDE.md` for working rules and `../plan_08052026.md` for the full project plan.

## Commands

```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # builds to dist/
npm run preview    # preview built output
npx astro check    # type-check .astro files
```
